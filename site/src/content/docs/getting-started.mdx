`ratatui-diff` is a widget, not an application. You prepare a `DiffDocument`, keep a `DiffState`
between frames, and render a `Diff` inside your own draw callback. Your application owns the
terminal, the event loop, key bindings, and where the source text comes from.

## Install

```sh
cargo add ratatui ratatui-diff
```

`ratatui-diff` 0.1 works with Ratatui 0.30, which re-exports the `ratatui-core` 0.1 types the widget
uses, and needs Rust 1.98 or later. The examples import Ratatui's re-exports, such as
`ratatui::buffer` and `ratatui::crossterm`, so these two crates are all they need. Rendering depends
only on `ratatui-core`, so the widget works with any Ratatui backend. The optional `syntax` feature
adds
[syntax colors](../guides/syntax/).

## The three pieces

| Type           | Lifetime                   | Role                                                                  |
| -------------- | -------------------------- | --------------------------------------------------------------------- |
| `DiffDocument` | Once per comparison        | Immutable files, hunks, lines, and word highlights. Prepare it once.  |
| `DiffState`    | As long as the view exists | Viewport, cached layout, folds, search, and selection.                |
| `Diff`         | One frame                  | Borrows the document and selects presentation options for this frame. |

Building a `Diff` is cheap; build it in the draw closure. Changing presentation (mode, wrapping,
theme) keeps the viewport anchored to the nearest source line. Rendering a different document resets
navigation on that render.

## Render before you navigate

Navigation methods like `scroll_pages`, `next_hunk`, and `scroll_to_source` need the viewport size
and row positions, which the state learns during rendering. Draw at least once before handling
navigation or hit-testing. Methods called between frames take effect on the next draw.

Tests and non-interactive code can render directly into a buffer:

```rust
use ratatui::buffer::Buffer;
use ratatui::layout::Rect;
use ratatui::widgets::StatefulWidget;
use ratatui_diff::{Diff, DiffDocument, DiffState};

let document = DiffDocument::from_text("hello world\n", "hello Rust\n");
let area = Rect::new(0, 0, 80, 20);
let mut buffer = Buffer::empty(area);
let mut state = DiffState::new();
let diff = Diff::new(&document);
diff.render(area, &mut buffer, &mut state);
state.scroll_pages(1);
```
