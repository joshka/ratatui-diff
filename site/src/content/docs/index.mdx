<CardGrid>
  <Card title="Any input" icon="document">
    Compare two strings, parse unified or multi-file Git patches, or supply structured files and
    hunks. See [Choose an input](./guides/inputs/).
  </Card>
  <Card title="Unified or split" icon="seti:image">
    Switch layouts without losing your place. Wrap long lines, show whitespace, hide numbers, and
    choose a theme. See [Appearance](./guides/appearance/).
  </Card>
  <Card title="Built for review" icon="magnifier">
    Jump by hunk or file, search source, fold files and unchanged context, and keep the current file
    header visible. See [Navigation](./guides/navigation/) and [Folding](./guides/folding/).
  </Card>
  <Card title="Exact source" icon="pencil">
    Selection copies the original bytes, never gutters or padding. Hit-testing maps terminal cells
    back to file, side, line, and byte. See [Selection](./guides/selection/).
  </Card>
  <Card title="Optional syntax colors" icon="seti:rust">
    Enable the `syntax` feature for bundled grammars and themes, composed underneath diff styling.
    See [Syntax colors](./guides/syntax/).
  </Card>
  <Card title="You own the app" icon="setting">
    Rendering depends only on `ratatui-core`. Your application keeps terminal setup, key bindings,
    files, and repository access.
  </Card>
</CardGrid>

The bundled viewer example cycles through unified view, split view, and visible whitespace. Run it
with `cargo run --example viewer`.
